Features

Everything you need for ReShade in Dead by Daylight

One app to install, preview, create and manage your presets.

One-click install

Finds the game, installs the latest ReShade, downloads the effects your presets need and activates the preset.

  • Offers to update ReShade when a new version is out
  • Won't install while the game is running or overwrite another mod's files
  • Launch game opens Steam, Epic or Xbox and starts Dead by Daylight

Always up to date

New presets arrive on their own, and the app updates itself with one click.

Try on maps

Preset Editor

How it works

From download to playing in four steps

No ReShade setup, no copying files into the game folder by hand.

  1. Download and open

    The app finds Dead by Daylight on Steam, Epic Games or the Xbox app by itself.

  2. Pick a preset

    Search the list, look at the preview, and open the creator's page if you want to know more.

  3. Try it on the maps

    See the preset with the real ReShade on every realm, before touching your game.

  4. Install and play

    One click installs ReShade, the effects and the preset. Press Home in game to open ReShade.

FAQ

Questions

Is DBD Reshade free?

Yes. DBD Reshade is free and open source (GPL-3.0). ReShade and the presets are free too.

Does it work with the Steam, Epic and Xbox versions?

Yes. It finds Dead by Daylight on Steam, Epic Games and the Xbox app / PC Game Pass automatically, or you can pick the game folder by hand.

Can I see a preset before installing it?

Yes. Try on maps shows any preset with the real ReShade on screenshots of every realm, without starting the game. You can also use your own screenshots.

Can I get banned for using ReShade?

ReShade is widely used by Dead by Daylight players and streamers, but there is no guarantee. Use it at your own risk.

Why does Windows SmartScreen warn about the app?

SmartScreen warns about apps that few people have downloaded yet. Download it only from the official GitHub releases page, then choose More info and Run anyway.

The preset is installed but nothing changes in game

Close the game, click Install preset again and start the game. Press Home: if the ReShade menu opens, the preset is active. If not, use Report a bug in the app and send us the log on Discord.

How do I remove ReShade from the game?

Run the official installer from reshade.me, select Dead by Daylight and choose Uninstall. Uninstalling DBD Reshade doesn't change the game.
